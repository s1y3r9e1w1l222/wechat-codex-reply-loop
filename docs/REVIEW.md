## 实施取舍及评审未判断的范围

- 按用户要求复用已登录 Codex，替代独立 AI API。代价是 CLI 启动延迟和账户额度，不提供额外 API 回退。
- 手机导航单独放入 `navigation.py`，使业务与通用 Runtime 适配分开；代价是多一个模块。
- 普通联系人身份、免打扰资料路径和真实个人／群区分尚未验收，因此默认名单为空并禁用未经校准的发送；代价是开发者仍需本机校准。
- 两个真实会话、长时间运行、现场多页重排、锁屏断线、其他尺寸语言和 App 均未验收，不能由离线测试推定；代价是当前支持范围有限。
- GitHub 远程 CI 与公开仓库行为须在确定目标仓库后验收；当前不公开发布。代价是尚无远程运行证据。
- 可安装插件包装和普通用户校准向导不在当前服务源码内；代价是目前需按 README 启动配套服务。
- 软件共享锁不能阻止人的触屏，运行时需独占手机交互；代价是不能同时人工使用该手机。
