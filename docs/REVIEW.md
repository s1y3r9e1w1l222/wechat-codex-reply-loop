### 本轮保留的实施裁决

1. 保留旧 CLI/模块，在现有引擎上扩展；若边界不足，后续适配器可能需要进一步抽取。
2. 清理测试必须创建真实关联轮次，不放宽发送检查点；代价是其他完整性前置仍需真实适配继续验证。
3. 正常三次回放使用不同合成正文，重复同文气泡仍按不确定处理；缺少稳定消息标识的真实布局可能需要人工核对。
4. 新控制客户端携带 App 标识并验证缓存状态；旧客户端保留兼容行为，没有新客户端的目标不匹配保护。
5. 两个新 App 真实界面按用户要求延期并保持禁用；不能提前宣称真实支持。
6. 没有验证真实模型文案/拒绝识别质量；后续仍需语言质量验证。
7. 锁屏、断连和两小时真机无人值守未验收；合成时钟与持久化通过不代表设备稳定性已通过。
8. 已交给手机 Runtime 的 tap 无法物理撤回；取消依赖提交前门槛和提交后不确定记录。
9. schema v2 为保留期增加时间戳，过期幂等结果压缩为不重复执行的记录；旧请求 ID 可能返回 expired，本地升级备份需要自行管理。
