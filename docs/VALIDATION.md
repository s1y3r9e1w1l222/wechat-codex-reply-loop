# 验证范围

本文件只记录脱敏结果，不保存原始聊天、截图或设备标识。版本 0.1.0 仍为实验版。

## 已完成

- Python 离线测试覆盖队列顺序、免打扰、消息重叠歧义、跨会话隔离、旧代次失效、共享锁、草稿保护、只提交一次及重启后不确定发送。
- 离线回放：两个合成会话从下往上发送；后面的 AI 先完成仍不能越序；免打扰联系人不参与。
- 独立本机进程实测模拟服务的 status / pause / resume / stop、私有控制 socket 和正常退出。不操作真实手机。
- 独立评审指出的 6 项重要问题已用先失败后通过的回归测试修复，整套 68 项测试通过。包括发送瞬间的新输入、相同未读再次出现、两遍扫描稳定性、AI 输入阻塞取消、首次预览、重试／基线转换和只读重启核对。修复后未重新连接真机，仍需后续设备验收。
- 已登录 Codex CLI 对虚构上下文生成真实回复，无另配 API key。使用系统已有代理后连通，未修改代理或读取认证令牌。
- 获设备所有者授权后，通过本项目发送路径向文件传输助手发送一条自测文本；核对了新增己方气泡和持久化 sent 状态，只点击一次发送。
- 发送后立即读取返回页面超时，记录为“已发送、返回需注意”，未重发；之后独立屏幕观察确认已回消息列表且预览包含该自测。
